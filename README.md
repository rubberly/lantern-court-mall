# Lantern Court Mall

A small walkable 3D mall (three.js r128). Six generic stores, clickable products, store directory and minimap.

- Desktop: drag to look, WASD or arrow keys to walk, Shift to hurry, click a product.
- Phone: left thumb to walk, drag on the right side to look, tap a product.

Static site: `index.html` + `three.min.js`. Deployed on Render from `render.yaml`.
